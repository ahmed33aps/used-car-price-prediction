# Data required for local execution

Raw third-party datasets are omitted from this public source repository because redistribution terms were not established. The original prepared private backup retains the supplied or separately sourced reference data. This public copy contains the analysis/source work, not a bundled dataset license.

## `car data.csv`

Restore an appropriately licensed local copy at this exact path before running the corresponding analysis. Expected columns:

`Car_Name`, `Year`, `Selling_Price`, `Present_Price`, `Driven_kms`, `Fuel_Type`, `Selling_type`, `Transmission`, `Owner`

The recorded validation applies to the locally prepared project with its data present. A fresh public clone will not run end to end until the required data is supplied. No new model results or full reproduction claim is made.
